# Support

## Where to ask

- **Questions and usage help:** [open an issue](https://github.com/LordeStudios/DeviceBoost/issues/new) and describe what you are trying to do.
- **Bug reports:** include your Windows version, GPU model and the steps to reproduce.
- **Feature requests:** open an issue tagged `enhancement`.

## Before opening an issue

1. Check the [README](README.md) installation and requirements sections.
2. Search the [issue tracker](https://github.com/LordeStudios/DeviceBoost/issues) for an existing report.
3. If the client shows "Host offline", confirm `deviceboost-host.exe start-host` is running and that nothing else binds `127.0.0.1:47820` / `47821`.

## What to include

- DeviceBoost version (from the release you downloaded).
- Windows version and build.
- The application you launched, if the problem involves launching.
- Relevant lines from the in-app activity log.

Please do not post personal data, licence keys or tokens in public issues.
